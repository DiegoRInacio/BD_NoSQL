Contexto — banco frota_db (transportadora / gestão de frota)

Todas as questões se referem a este banco. Os dados vieram de várias filiais e estão sujos de propósito.

// coleção: veiculos
{ _id, placa: " abc1d23 ",        // aparece com espaços e caixa trocada
  modelo, tipo: "van"|"caminhao"|"moto", ano,
  km_rodados: 84000,              // em alguns docs vem como "84000" (string)
  ativo: true,                    // aparece como true, "sim" e 1
  filial, tags: [ ... ],
  abastecimentos: [ ISODate(...), ISODate(...), ... ],   // array append-only, cresce sem limite
  manutencoes: [ { data: ISODate(...), tipo, custo } ]   // NEM todo veículo tem esse campo
}

// coleção: motoristas
{ _id, nome, cnh, categoria_cnh: "B"|"D"|"E", cidade,
  terceirizado: true|false, habilitacoes: [ ... ],
  admissao: ISODate(...) }        // em alguns docs vem como "2023-02-10" (string)

// coleção: viagens
{ _id, veiculo_placa: "ABC1D23",
  motorista_id: ObjectId(...),    // em ALGUMAS viagens foi gravado como String (bug)  -> aponta para motoristas._id
  origem, destino, km, carga_kg,
  status: "concluida"|"em_curso"|"cancelada",
  saida: ISODate(...),
  itens_entrega: [ { nf, valor } ] }

Problemas conhecidos: placa com espaços/caixa; ativo com tipos mistos; km_rodados ora número ora string; admissao ora data ora string; viagens.motorista_id ora ObjectId ora String; abastecimentos sem limite de tamanho; nem todo veículo tem manutencoes.
