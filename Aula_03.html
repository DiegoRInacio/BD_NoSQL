📘Conceitos do CRUD

CRUD são as quatro operações fundamentais em qualquer banco de dados:

🟢 C → Create (criar): Inserir novos documentos em uma coleção
🔵 R → Read (ler/consultar): Consultar dados armazenados
🟠 U → Update (atualizar): Alterar informações de documentos existentes
🔴 D → Delete (excluir): Remover documentos do banco

🧩 MongoDB vs SQL

Operação Em bancos SQL No MongoDB Para que serve
CREATE INSERT INTO ... insertOne, insertMany Adicionar documentos
READ SELECT ... FROM ... find, findOne Consultar documentos
UPDATE UPDATE ... SET ... updateOne, updateMany Alterar documentos
DELETE DELETE FROM ... deleteOne, deleteMany Remover documentos

🟢CREATE - Inserir Dados (mongosh)

💡 Inserir UM documento
db["aula_crud"].insertOne({
  nome: "Zé da Manga",
  idade: 23,
  curso: "Engenharia",
  notas: [8.5, 9.0, 7.0],
  ativo: true
})
💡 Inserir VÁRIOS documentos de uma vez
db["aula_crud"].insertMany([
  {
    nome: "Bruno",
    idade: 21,
    curso: "Medicina",
    notas: [9.5, 8.0],
    ativo: true
  },
  {
    nome: "Carla",
    idade: 25,
    curso: "Direito",
    notas: [7.0, 6.5, 8.0],
    ativo: false
  },
  {
    nome: "Diego",
    idade: 22,
    curso: "Computação",
    notas: [8.0, 9.0],
    ativo: true
  }
])

🔑 Conceitos importantes:

  • insertOne: Adiciona um único documento
  • insertMany: Adiciona múltiplos documentos em uma operação
  • MongoDB gera automaticamente um _id único
  • Documentos podem ter estruturas diferentes (flexibilidade)

🔵READ - Consultar Dados (mongosh)

💡 Buscar TODOS os documentos
db["aula_crud"].find()
💡 Buscar por um campo específico
db["aula_crud"].find({ nome: "Zé da Manga" })
💡 Buscar com filtro (idade maior que 22)
db["aula_crud"].find({ idade: { $gt: 22 } })
💡 Buscar com projeção (mostrar apenas nome e curso, sem _id)
db["aula_crud"].find(
  { ativo: true },
  { nome: 1, curso: 1, _id: 0 }
)

🔑 Operadores de consulta:

  • $gt: maior que
  • $lt: menor que
  • $gte: maior ou igual
  • $lte: menor ou igual
  • $ne: diferente
  • $in: está na lista

🟠UPDATE - Atualizar Dados (mongosh)

💡 Atualizar UM documento ($set: muda ou cria o campo)
db["aula_crud"].updateOne(
  { nome: "Zé da Manga" },
  { $set: { ativo: false } }
)
💡 Atualizar VÁRIOS documentos
db["aula_crud"].updateMany(
  { curso: "Engenharia" },
  { $set: { curso: "Engenharia Software" } }
)
💡 Incrementar a idade de todos em +1
db["aula_crud"].updateMany(
  {},
  { $inc: { idade: 1 } }
)
💡 Adicionar uma nova nota em um array
db["aula_crud"].updateOne(
  { nome: "Bruno" },
  { $push: { notas: 10 } }
)

🔑 Operadores de atualização:

  • $set: define valor (cria se não existe)
  • $inc: incrementa valor numérico
  • $push: adiciona item ao array
  • $pull: remove item do array
  • $unset: remove campo

🔴DELETE - Remover Dados (mongosh)

💡 Deletar UM específico
db["aula_crud"].deleteOne({ nome: "Carla" })
💡 Deletar TODOS de um curso
db["aula_crud"].deleteMany({ curso: "Medicina" })
💡 Deletar TODOS da coleção
db["aula_crud"].deleteMany({})
⚠️ ATENÇÃO: Sempre teste o filtro com find() antes de executar deleteMany()!
⚡ EXTRA - Contagem e limpeza
// Contar quantos documentos de Engenharia
db["aula_crud"].countDocuments({ curso: "Engenharia" })

// Limpar terminal no Compass
.clear()
// ou atalho CTRL+L / CMD+K

🔑 Boas práticas:

  • deleteOne: remove apenas o primeiro documento encontrado
  • deleteMany: remove todos os documentos que atendem ao filtro
  • Use filtros específicos para evitar exclusões acidentais
  • Sempre faça backup antes de operações de exclusão em massa

🐍CREATE - Python com PyMongo

💡 Configuração inicial
from pymongo import MongoClient

# Conexão
client = MongoClient("mongodb://localhost:27017")
db = client["aula_mongo"]
alunos = db["aula_crud"]
💡 Inserir UM documento
alunos.insert_one({
    "nome": "Zé da Manga",
    "idade": 23,
    "curso": "Engenharia",
    "notas": [8.5, 9.0, 7.0],
    "ativo": True
})
💡 Inserir VÁRIOS documentos
alunos.insert_many([
    {
        "nome": "Bruno",
        "idade": 21,
        "curso": "Medicina",
        "notas": [9.5, 8.0],
        "ativo": True
    },
    {
        "nome": "Carla",
        "idade": 25,
        "curso": "Direito",
        "notas": [7.0, 6.5, 8.0],
        "ativo": False
    },
    {
        "nome": "Diego",
        "idade": 22,
        "curso": "Computação",
        "notas": [8.0, 9.0],
        "ativo": True
    }
])

🔵READ - Python com PyMongo

💡 Buscar TODOS os documentos
# Retorna uma lista com todos os documentos
list(alunos.find())
💡 Buscar por um campo específico
# Retorna apenas um documento (ou None)
alunos.find_one({"nome": "Zé da Manga"})
💡 Buscar com filtro (idade maior que 22)
# Converte cursor em lista
list(alunos.find({"idade": {"$gt": 22}}))
💡 Buscar com projeção
# Apenas nome e curso, sem _id
list(alunos.find(
    {"ativo": True},
    {"nome": 1, "curso": 1, "_id": 0}
))

🧠 Dicas importantes:

  • find(): retorna um cursor → converta com list()
  • find_one(): retorna um dict ou None
  • Use from bson import ObjectId para trabalhar com _id
  • Filtros usam a mesma sintaxe do mongosh

🟠🔴UPDATE & DELETE - Python

🟠 UPDATE

Atualizar UM
alunos.update_one(
    {"nome": "Zé da Manga"},
    {"$set": {"ativo": False}}
)
Atualizar VÁRIOS
alunos.update_many(
    {"curso": "Engenharia"},
    {"$set": {"curso": "Eng. Software"}}
)
Incrementar
alunos.update_many(
    {},
    {"$inc": {"idade": 1}}
)
Adicionar ao array
alunos.update_one(
    {"nome": "Bruno"},
    {"$push": {"notas": 10}}
)

🔴 DELETE

Deletar UM
alunos.delete_one({
    "nome": "Carla"
})
Deletar VÁRIOS
alunos.delete_many({
    "curso": "Medicina"
})
Deletar TODOS
# ⚠️ CUIDADO!
alunos.delete_many({})
Contar documentos
alunos.count_documents({
    "curso": "Engenharia"
})
⚠️ Lembre-se: Os métodos de atualização e exclusão retornam objetos com informações sobre quantos documentos foram afetados.

🎯Resumo e Boas Práticas

📋 Checklist CRUD MongoDB

🟢 CREATE

  • ✅ insertOne() para um documento
  • ✅ insertMany() para vários
  • ✅ MongoDB gera _id automaticamente

🔵 READ

  • ✅ find() para múltiplos
  • ✅ findOne() para um só
  • ✅ Use projeção para campos específicos

🟠 UPDATE

  • ✅ $set para definir valores
  • ✅ $inc para incrementar
  • ✅ $push/$pull para arrays

🔴 DELETE

  • ✅ Sempre teste com find() antes
  • ✅ deleteOne() vs deleteMany()
  • ✅ Faça backup antes de exclusões grandes

💡 Dicas de Ouro

🎯 Filtros específicos: Use filtros precisos para evitar operações em documentos errados
🔍 Teste sempre: Execute find() com seus filtros antes de update ou delete
📊 Monitore performance: Use countDocuments() para verificar quantos documentos serão afetados
🔒 Segurança: Sempre valide dados antes de inserir e use filtros específicos
🎓 Prática: Execute estes comandos no Compass para fixar o aprendizado
